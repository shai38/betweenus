# BetweenUs

BetweenUs — Telegram-бот для пар. Он помогает создать пару по коду приглашения и вести общий список планов. Бот предназначен для личных чатов; один пользователь может состоять только в одной паре.

## Команды

- `/start` — начать и создать пару или присоединиться к партнёру.
- `/plans` — показать общий список планов.
- `/addplan` — добавить план.
- `/help` — показать справку.
